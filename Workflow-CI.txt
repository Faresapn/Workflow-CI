## GitHub Actions Workflow
File: .github/workflows/workflow-ci.yml
- Trigger: push ke main branch, pull request, dan workflow_dispatch
- Environment: Ubuntu latest, Python 3.9
- Steps:
  1. Checkout repository
  2. Set up Python 3.9
  3. Install dependencies (mlflow, scikit-learn, pandas, numpy, dll)
  4. Run MLflow training (mlflow run . --env-manager local)
  5. Upload artifacts (mlruns/, model files)
